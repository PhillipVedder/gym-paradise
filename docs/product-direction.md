# Agreed product direction

The user wants to design, explore, and share a dream private gym. Primary platform: iPhone; laptop use must also be supported. Exploration is first person. Budget: preferably no additional purchases. The user is a recent computer science graduate who wants to build collaboratively.

Visual direction approved: Fitness Cartel-inspired warehouse scale, contemporary strength machines, purple/cyan/white lighting, long mirror and dumbbell walls, expressive wall art. Use the supplied references as inspiration. Create an original environment.

Supported machine families should eventually include Hammer Strength and Technogym. Recognising the exact machine is separate from obtaining a verified 3D asset. If an exact model is unavailable, offer a clearly labelled similar model while preserving the exact item on a wishlist. Do not represent approximate geometry as an exact manufacturer model.

First milestone: editable gym, first-person exploration, browser-local save, and both input styles. After that: richer equipment and decoration, reliable phone tours and sharing, equipment photo identification/catalogue matching, and eventually progress logging.

Cross-device availability does not imply syncing in this prototype: users export/import layout files. Cloud account sync is a separate future milestone.

The initial phone/laptop build is a practical prototype; the approved generated concept remains the visual target, not evidence of actual rendering fidelity or performance.
