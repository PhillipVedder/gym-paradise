# Roadmap

This is a prioritised direction, not a delivery-date commitment. The primary experience remains **design, explore and share a dream gym**, with iPhone as the first physical-device target and laptop support alongside it.

## Available

- [x] 36 equipment types and a complete example gym.
- [x] 3D preview placement, overlap/bounds checks, rotate, trash, undo/redo.
- [x] Orbit/pan build controls and first-person exploration.
- [x] Room dimensions, surfaces, lights, murals, mirrors, turf and equipment colours.
- [x] Private state/media storage, conflict protection, recoverable drafts.
- [x] Equipment photo collection, manual brand/model notes and optional recognition assistance.
- [x] Training records, portable layout export, screenshots and supported video capture.
- [x] Reproducible local demo, documented architecture and automated CI.

## Next: validate the experience

- [ ] Test on physical iPhones; measure a full showcase during prolonged exploration and capture.
- [ ] Add repeatable browser interaction tests for placement, undo and touch navigation.
- [ ] Audit keyboard and screen-reader paths, especially canvas-only interactions.
- [ ] Measure GPU costs and prioritise the highest-impact rendering improvements.
- [ ] Test the local setup on Windows.

## Then: deepen the gym builder

- [ ] Build a verified brand/model catalogue with dimensions, source links and confidence states.
- [ ] Add licensed, downloadable, mobile-optimised equipment models where available.
- [ ] Keep an explicitly labelled similar model when an exact asset is unavailable.
- [ ] Extend artwork, mirror and zone placement beyond the current single-region controls.
- [ ] Design arbitrary floor plans once placement and collision rules support them.

## Later: sharing and community

- [ ] Public read-only gym links with explicit sharing/privacy choices.
- [ ] Tour exports tuned for vertical social video.
- [ ] Creator profiles and discovery, after public-content and storage requirements are defined.

Automatic exact-machine recognition, a marketplace, multiplayer, and a mobile app-store release are not existing features. The current project does not imply partnerships with equipment manufacturers or referenced gyms.
